Sobre este Projeto

Este sistema foi desenvolvido como requisito para a disciplina de Desenvolvimento Web Back-End.

O que foi implementado:

  • ✓ Design Moderno: Interface baseada no estilo IMDb, responsiva e com fontes do Google Fonts (Poppins).
  • ✓ Banco de Dados MySQL: Armazenamento persistente das sugestões via tabela sugestoes_filmes.
  • ✓ Conexão Segura: Uso da extensão PDO do PHP com tratamento de exceções (ATTR_ERRMODE).
  • ✓ Segurança contra SQL Injection: Utilização exclusiva de Prepared Statements (bindParam).
  • ✓ Segurança contra XSS: Saída de dados do banco protegida com htmlspecialchars() no index.php.
